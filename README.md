# 我是歪果仁 · 抖音属地代理（LSPosed 模块）

一个 LSPosed 模块：**只把抖音的主页刷新 / 评论 / 发作品请求走 SOCKS5 代理**，让 IP 属地长期显示为代理所在地区；**视频流、私信聊天、直播保持直连**，不影响日常网速。

## ✨ 功能特性

- 三个独立开关：**主页 IP 替换 / 评论 IP 替换 / 发视频 IP 替换**
- 只代理命中的接口请求，视频 / 私信 / 直播等流量全部直连
- 入口注入抖音侧边栏「未成年人保护」卡片第一行（黑色「周」字样式）
- 抽屉式设置面板：磨砂玻璃效果，上滑伸展、松手回弹
- SOCKS5 代理串 **AES-256-GCM 加密存储**，保存后不再明文显示
- 状态行实时显示代理状态 + 经代理解析出的预计 IP 与地区

## 📦 安装

1. 手机已 Root 并安装 [LSPosed](https://github.com/LSPosed/LSPosed)（Zygisk / Riru 均可）
2. 从 Releases 下载 APK 安装
3. 在 LSPosed 中启用「我是歪果仁」，作用域勾选 **抖音**
4. 强制停止抖音后重新打开

## 🚀 使用

1. 打开桌面 App「我是歪果仁」（弹跳文字界面）
2. 进入抖音 → 打开侧边栏 → 点击「未成年人保护」卡片第一行的「周」字行
3. 在弹出的抽屉中输入 SOCKS5 代理并保存，支持格式：
   - `socks5://用户名:密码@主机:端口`
   - `用户名:密码@主机:端口`
   - `主机:端口`
4. 按需打开「主页 IP / 评论 IP / 发视频 IP」开关
5. 清空输入框再保存 = 删除已配置的代理

## 🔧 编译

环境：JDK 17 + Android SDK + Gradle 8.9

```bash
export JAVA_HOME=/path/to/jdk17
gradle assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`
